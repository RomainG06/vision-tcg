✨ Key Features

🌙 Dark Mode First
All colors tuned for dark backgrounds with magical glows and high contrast.
✨ Magical Effects
Glowing runes, arcane borders, pixel sparkles — heroic fantasy magic woven throughout.
🎪 Pixel Accents
Subtle pixelization in corners, dividers, and micro-details — not overwhelming.
📏 Responsive Grid
Desktop: 3 columns. Mobile: 1 column + fixed bottom navigation.
🛡️ Heroic Icons
5 custom SVG icons: Sword, Crystal, Grimoire, Scroll, Crown.
🎨 Design Tokens
JSON tokens export for Tailwind, CSS custom properties, or any framework.

🛠️ Implementation Quick Start

1. Load Design Tokens
Import tokens/tokens.json into your Tailwind config or create CSS custom properties.

2. Build Card Component
Use card-template.svg as reference for structure, borders, and magical accents.

3. Use Icon System
All 5 icons available as SVG in assets/icon-*.svg. Recommended: SVG sprites or inline imports.

4. Add Animations
Card hover: scale(1.02) + glow-pulse | Button hover: pixel-flicker + glow-pulse | Price: always glowing

5. Set Responsive Breakpoints
Desktop: 1440px (3-col grid) | Mobile: 375px (1-col grid + bottom nav)
